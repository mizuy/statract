# 次の速度改善

公開データでの計測のあと、完全一致と CEM の直積、Cox の死亡時刻ごとの全走査は直した。残っている差は、次の順で潰す。

1. アルゴリズムを変える。同じ数値のまま、無駄な計算を消す。
2. それでも Python の数値ループが残る内側だけ、numba にする。
3. numba のあとでも R の Fortran や Eigen に届かない核だけ、最後に Rust を検討する。

既存ライブラリへの載せ替えは 1 に含める。いまのエンジンで数値も速度も足りているものは、そのままにする。

速度の合格ラインは [ベンチマークの設計](benchmark-plan.md) には置いていない。この計画での目安は、大きい側（おおよそ 10,000 行）で、下の「目安」に書いた比である。数値の許容差は [R パッケージとの対応](../models/vs-r.md) のまま緩めない。計測手順も同じで、ウォームアップ 1 回のあと 5 回の中央値、スレッドは 1 本。**いまの CSV の秒と誤差の一覧は [Benchmarks](../models/benchmarks.md)**（下表は計画当時のメモで、CSV と違う行がある）。

## 1. アルゴリズム

一つずつ入れ、そのたびに `bench/stat` と、対応する pytest の fixture を見る。

### ロジット最近傍

`_nearest` は、処置 1 人ごとに対照全員の距離を作り、未使用の中から近い順を mergesort している。傾向スコアは一次元なので、対照をスコア順に並べ、未使用の最近傍を二分探索で取る。同点は MatchIt 4.5.5 と同じく、安定なスコア順で隣の対照を取り、差が等しければ低いスコア側を残す。`order="data"`、非復元、キャリパー、`exact` の層はこの順のまま残す。

マハラノビスは行列距離なので、この二分探索には載せない。因子をダミーにしたあと、速度が問題になってから別にする。

目安は、大きい側で R の 0.67 秒以下。

### 使わない傾向スコア

`match_sample` は、完全一致と CEM でも既定でロジットを当てている。重みはその距離を使わない。CEM の 0.17 秒の大半は、この GLM である。距離は、`distance` を明示したときと、`balance()` が距離の行を要るときだけ計算する。重み、サブクラス、`pairs()` の中身は変えない。

### Cox の同点

時刻の遅い方から十分統計量を一度ずつ足す走査は入っている。残る時間は、Efron の同点グループを Python で一つずつ補正している部分である。SUPPORT2 では同点グループが多く、最大の組は 200 人を超える。同点補正を、グループをまたいで配列のまま計算する。Breslow は同点補正がないので、この変更の対象は Efron と、Efron を層ごとに繰り返す層別である。

目安は、アルゴリズムのあとで大きい側が R の 3 倍未満。3 倍を超えて残ったら、次の numba に回す。

### 変量傾き

29 秒は mixedlm の REML である。生徒が数千人で、最適化の各ステップがスパースなコレスキーを Python から呼んでいる。この段では分解を書き換えない。STAR の同じ式で、反復回数と、尤度 1 回の秒を残す。境界で反復が伸びているなら、モーメント法の初期値と収束判定だけを調整する。数値は fixture の許容差の中に置く。

目安は、この段では「反復と 1 回の秒が記録されていること」。lme4 の 0.19 秒に合わせることは、この段の目標にしない。

## 2. 既存ライブラリ

載せ替えるなら、fixture の係数、標準誤差、尤度がいまの許容差に入ることが先である。速度だけを理由にしない。

| 関数 | 続けるエンジン | 検討するもの |
|---|---|---|
| Cox | 自前の部分尤度 | scikit-survival の Cox。fixture で Efron の係数と標準誤差が一致したときだけ |
| 最近傍 | 自前の `_nearest` | ペアの順が MatchIt と一致する実装は見当たらないので、自前を続ける |
| 混合モデル | mixedlm-rs | 相関つき REML を保つ既存ライブラリ。実施の節で測って替えた |
| GLM / OLS | 二項・ポアソン・ガンマは自前の IRLS。ガウス GLM と OLS は statsmodels | 大きい側を R の 2 倍以内にした。詳細は実施のあとの節 |

lifelines の Cox は Python 実装で、`coxph` の Efron と標準誤差の取り方が違う。速度の候補にはしない。実行時に R を呼ぶ経路は、これまで通り入れない。

## 3. numba

1 を入れたあとに、同じ計測を取り直す。大きい側で R の 3 倍を超え、かつ内側が Python の数値ループであるものだけを numba にする。

対象になるのは、次の二つである。

- Cox のリスク集合走査と Efron の補正。Polars はループの外に置き、配列だけをコンパイルする。
- 最近傍で、二分探索のあとにまだ Python のループが秒を占めているとき。一次元の探索が効いていれば、ここは空になる。

次は numba にしない。

- GLM と OLS。statsmodels の IRLS は既にコンパイルされたコードである。
- mixedlm のスパース分解。scipy のスパースが既にコンパイルされており、numba はその呼び出しを速くしない。
- sandwich、lmtest、GAM、AFT。大きい側では既に R より短い。

numba を依存に足すのは、核を一つ入れたときである。計測のウォームアップ 1 回にコンパイルを含め、中央値にはコンパイル時間を入れない。

目安は、numba を入れた Cox で、大きい側が R の 2 倍未満。

## 4. Rust

numba のあと、大きい側がまだ R の 3 倍を超える核だけを対象にする。小さな数値核に限り、混合モデル全体の移植は既定ではしない。

- Cox の部分尤度と勾配。numba で 2 倍未満に届かなかったとき、既存の Rust 拡張の隣に、走査だけの関数を足すことを検討する。
- 変量傾き。スパースな REML を自前にすると、lme4 の罰則最小二乗を別実装することになる。mixedlm の反復を調整したあとも 10 秒を超えて残る。実施の節で既存ライブラリを測り、エンジンは mixedlm-rs に替えた。

## 進める順

1. ロジット最近傍を、スコア順の二分探索にする。
2. 完全一致と CEM の傾向スコアを、要るときだけ計算する。
3. Cox の Efron 補正を、グループ横断の配列計算にする。
4. 変量傾きについて、反復回数と尤度 1 回の秒を記録し、初期値で縮むならそれだけ変える。
5. `bench/stat` を取り直す。
6. 3 倍を超えて残った Python の数値ループを numba にする。
7. そのあとまだ 3 倍を超える核だけ、Rust の要否を書く。

各段の終わりに、対応する fixture が同じ許容差で通ることを確認する。ペアの順序を変える最近傍は、既存の最近傍テストの期待する対照が、同じ同点規則で一致することを確認する。

## 実施

大きい側を、ウォームアップ 1 回のあと 5 回の中央値で取り直した。R の秒は変えていない。混合モデルの 3 行は、エンジンを mixedlm-rs にしたあとの再計測である。

| タスク | 以前 | いま | R | 比 |
|---|---:|---:|---:|---:|
| ロジット最近傍 | 1.13 秒 | 0.167 秒 | 0.668 秒 | 0.25 |
| 完全一致 | 0.021 秒 | 0.0028 秒 | 0.005 秒 | 0.56 |
| CEM | 0.17 秒 | 0.011 秒 | 0.066 秒 | 0.16 |
| Cox Efron | 0.179 秒 | 0.031 秒 | 0.031 秒 | 0.99 |
| Cox Breslow | 0.062 秒 | 0.019 秒 | 0.026 秒 | 0.71 |
| Cox 層 | 0.207 秒 | 0.043 秒 | 0.031 秒 | 1.38 |
| 変量傾き REML | 29.2 秒 | 0.025 秒 | 0.190 秒 | 0.13 |
| 変量切片 REML | 0.214 秒 | 0.017 秒 | 0.072 秒 | 0.24 |
| 変量切片 ML | 0.215 秒 | 0.017 秒 | 0.073 秒 | 0.23 |

ロジット最近傍は、スコア順の二分探索にした。その内側は numba で回す。同点は MatchIt 4.5.5 と同じく、安定なスコア順で隣の対照を取り、差が等しければ低いスコア側を残す。組と重み、マッチ後の標準化差は R と一致する。再計測は 10,000 行 43.80 ms（比 0.065）、1,000 行 7.59 ms（比 0.379）で、[ベンチマーク](../models/benchmarks.md) と同じである。上の表の 0.167 秒は、この同点規則の前の計測である。

完全一致と CEM は、距離を省略したときロジットを当てない。`frame`、`pairs`、`balance` が距離を読むときに計算する。重みは fixture の許容差に入る。

Cox の通常の生存時間は、時刻の遅い方からの走査を numba にした。Efron と Breslow、層別の係数と対数尤度は fixture の許容差に入る。カウント過程はこれまでと同じ Python の走査である。

マハラノビス距離は、因子の全水準を sqrt(2) で割った指標にし、尺度とプールした共分散、ピボット付き Cholesky の座標で距離を取る。ユークリッド長が等しいときは、先に並ぶ対照を残す。組は R と一致する。尺度と共分散は long double の逐次和のままである。和は `cumsum` と long double の内積で、対ごとの `np.sum` は使わない。距離の二乗は同じ einsum を、一時配列がキャッシュに収まるタイルで計算する。再計測は 1,000 行 10.76 ms（比 0.672）、10,000 行 737.8 ms（比 0.721）で、[ベンチマーク](../models/benchmarks.md) と同じである。

変量傾きは、STAR の 10,000 行、生徒 3,305 人で、mixedlm 1.2 が反復 53 回、尤度評価 52 回、1 回あたり 0.55 秒、合計 28.7 秒だった。収束しており、境界停止ではなかった。EM による初期値は、このフィットより長くかかったので使っていない。評価 1 回がスパース分解の時間なので、反復を半分にしても 10 秒は残る。

同じ式 `read ~ 共変量 + (1 + grade | student)` を、スレッド 1、ウォームアップ 1 回のあと 5 回の中央値で比べた。R の lme4 は 1,000 行で 0.030 秒、10,000 行で 0.190 秒である。STAR の変量効果の相関はほぼ 1 で、独立な傾きは別のモデルになる。

| ライブラリ | モデル | 1,000 行 | 10,000 行 | 固定効果 | 変量共分散 |
|---|---|---:|---:|---:|---:|
| mixedlm 1.2 | 相関つき REML | 0.141 秒 | 28.7 秒 | 7.9e-5 | 4.0e-5 |
| lme4 | 相関つき REML | 0.030 秒 | 0.190 秒 | 基準 | 基準 |
| mixedlm-rs 0.2.0 | 相関つき REML | 0.026 秒 | 0.101 秒 | 6.5e-5 | 2.6e-5 |
| glmm 0.3.2 | 相関つき REML | 0.0037 秒 | 0.039 秒 | 7.4e-4 | 4.9e-4 |
| lme-python 0.2.6 | 相関つき REML | 0.025 秒 | 0.78 秒 | 1.2e-3 | 9.1e-4 |
| gpboost | 独立な傾き、周辺 ML | 0.032 秒 | 0.56 秒 | 2.7 | 別モデル |
| statsmodels MixedLM | 相関つき REML | 0.59 秒 | 計測せず | 2.7（1,000 行） | 10.7（1,000 行） |

固定効果と変量共分散は、10,000 行での lme4 に対する最大相対誤差である。statsmodels は 1,000 行の lbfgs が別の点に収束したので、10,000 行は計測していない。既定の最適化でも 1.6 秒で相対誤差 0.44 だった。gpboost は切片を共変量に入れても、傾きの分散が lme4 の 1.70 に対して 0.065 だった。

`fit_mixed` のエンジンは当時 mixedlm-rs にした。**その後の既定は lme-python（lme-rs）**で、二項 `glmer` も同じ入口である。mixedlm-rs は `engine="mixedlm_rs"`。STAR の 10,000 行は相関が 1 に近く、lme-python の相対誤差は上表のとおり mixedlm-rs より大きい。小さい標本の fixture は vs-r を参照。

numba は Cox の走査と、最近傍の一次元探索に入れた。Cox Efron は R の 0.99 倍、層別は 1.38 倍で、2 倍未満である。Rust の核は足していない。

## R の 2 倍以内

上の実施のあと、大きい側で比が 2 を超えて残っていた推定を、同じ許容差のまま縮めた。ウォームアップ 1 回のあと 5 回の中央値、スレッドは 1 本。R の秒は変えていない。「以前」はこの節の直前の再計測である。

| タスク | 以前 | いま | R | 比 |
|---|---:|---:|---:|---:|
| OLS | 0.016 秒 | 0.0099 秒 | 0.006 秒 | 1.66 |
| 重みつき OLS | 0.016 秒 | 0.0098 秒 | 0.008 秒 | 1.22 |
| 二項 GLM | 0.154 秒 | 0.021 秒 | 0.054 秒 | 0.39 |
| ガンマ GLM | 0.081 秒 | 0.010 秒 | 0.028 秒 | 0.37 |
| ポアソン GLM | 0.229 秒 | 0.033 秒 | 0.090 秒 | 0.36 |
| 性別ごとの Kaplan–Meier | 0.012 秒 | 0.0028 秒 | 0.004 秒 | 0.70 |
| ログランク（ρ = 0） | 0.016 秒 | 0.0017 秒 | 0.007 秒 | 0.25 |
| ログランク（ρ = 1） | 0.016 秒 | 0.0019 秒 | 0.006 秒 | 0.31 |
| 層別ログランク | 0.023 秒 | 0.0030 秒 | 0.004 秒 | 0.74 |

因子のダミーは、水準を整数コードにしてから一括で書いている。短い列は辞書、長い列は Polars の置換である。OLS と重みつき OLS の当てはめ自体は statsmodels のままである。

二項、ポアソン、ガンマは、収束した重み付き最小二乗の係数と重みを一つの IRLS で取り、正規方程式で解く。特異なステップだけ最小二乗分解に戻す。ガウス GLM は statsmodels のままである。二項の 10,000 行は、statsmodels が分離で別の点に止まっていた係数も、R の rtol 1e-6 に入るようになった。対数尤度と標準誤差の許容差は変えていない。

Kaplan–Meier と Nelson–Aalen は、同時点のイベント数を `reduceat` で足す。ログランクは群ごとの死亡とリスク集合を同じ形で足し、分散は外積の和である。1,000 行側のポアソン、Kaplan–Meier、Nelson–Aalen、ログランク、OLS も 2 倍以内である。1,000 行の OLS は 0.0022 秒で、R の 0.002 秒に対する比は 1.12 である。

## Numba を足した走査

比が 1 前後のもののうち、内側がまだ Python の数値ループだったのはマハラノビス最近傍だけである。OLS と重みつき OLS の残りは設計行列と statsmodels の分解で、Numba の対象になるループはない。Cox の部分尤度は既に Numba で、Efron は R の 0.98 倍、層別は 1.37 倍、差は数ミリ秒である。2 変数のクラスタ頑健は配列の和で、比は 1.03 である。

1 倍未満でも、行ごとの Python ループが時間の大半なら Numba に載せた。GAM の三次回帰基底がそれである。ペナルティの小さい行列はそのままである。

| タスク | 以前 | いま | R | 比 |
|---|---:|---:|---:|---:|
| マハラノビス最近傍 | 2.17 秒 | 0.172 秒 | 1.386 秒 | 0.12 |
| GAM（k=8） | 0.044 秒 | 0.0043 秒 | 0.116 秒 | 0.037 |
| GAM（k=10） | 0.047 秒 | 0.0073 秒 | 0.149 秒 | 0.049 |

マハラノビスは、処置ごとに対照全員との距離を安定ソートしていた。Numba では同じ同点規則（ユークリッド長が等しければ対照の並びが早い方）で、上位だけを残す。この段の秒は、共分散を MatchIt の long double に合わせる前のものである。1,000 行は 0.022 秒から 0.0034 秒、比は 0.20 である。合わせたあとの秒は上の再計測である。GAM の係数のずれは以前と同じで、10,000 行の係数だけ rtol 1e-6 を超えたままである。

ベンチの外でも、行数に比例する Python の数値ループが残っていた。SUPPORT の 9,103 行（死亡 6,199、時刻 1,724）で、ウォームアップのあと 5 回の中央値は次のとおりである。累積発生と Fine–Gray は、死亡を 2 原因に分けた同じデータである。

| 処理 | 以前 | いま |
|---|---:|---:|
| Aalen–Johansen の分散 | 1.52 秒 | 0.028 秒 |
| Schoenfeld 残差 | 1.36 秒 | 0.010 秒 |
| スコア残差 | 1.24 秒 | 0.009 秒 |
| Harrell の C | 1.22 秒 | 0.256 秒 |
| Fine–Gray の行展開 | 0.67 秒 | 0.065 秒 |
| マルチンゲール残差 | 0.134 秒 | 0.0008 秒 |
| 比例ハザードのスコア検定 | 0.132 秒 | 0.0088 秒 |

累積発生の分散は、時点ごとの二重ループを前方への累積にしている。スコア残差は以前の値と一致し、重みつき Cox の共分散も変わらない。Harrell の C は単位重みで一致する。マルチンゲール、Schoenfeld、比例ハザード検定は和の順序が変わり、差は絶対値で 1e-12 程度である。Fine–Gray の展開行は以前と同じである。
