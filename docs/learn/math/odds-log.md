## 確率空間 {#probability-space}

確率を扱うには、まず「何が起こりうるか」を決めます。決めるものは三つです。

- **標本空間** $\Omega$（オメガ）：起こりうる結果をすべて集めたもの。サイコロを 1 回振るなら $\Omega = \{1, 2, 3, 4, 5, 6\}$ です。患者を 1 人選んで切除後の経過を見るなら、$\Omega$ はその患者に起こりうる経過すべてです。
- **事象**：標本空間の一部分。「偶数の目が出る」は $\{2, 4, 6\}$ です。「出血する」は、起こりうる経過のうち出血するものを集めた事象です。
- **確率** $P$：事象ごとに、0 から 1 の数を割り当てるきまり。

確率は、次の約束を守ります。

- どの事象 $A$ でも $0 \le P(A) \le 1$
- 何かは必ず起こるので $P(\Omega) = 1$
- 同時には起こらない事象 $A$ と $B$ なら、$P(A \text{ または } B) = P(A) + P(B)$

この約束から、たとえば「$A$ が起こらない確率」は $1 - P(A)$ だとわかります。サイコロなら、どの目も確率 $1/6$ なので、偶数の目が出る確率は $1/6 + 1/6 + 1/6 = 1/2$ です。

標本空間、事象、確率の三つの組を**確率空間**と呼びます。厳密に定めるには測度論という数学が要りますが、本書ではこの理解で十分です。

### 確率の読み方

100 人中 5 人が出血したら、出血割合は $5/100 = 0.05$ です。これを、1 人の患者が出血する確率 $p$ と考えます。同じ状況を何度も繰り返したときに起こる割合として確率を読む見方です。第 13 章のベイズ推論では、確率を「どのくらい確からしいか」の度合いとしても読みます。

## 確率変数 {#random-variable}

標本空間の結果は、「出血した経過」や「6 の目」のように、ことばや記号のこともあります。計算するには数に直します。結果 $\omega$ ごとに数を一つ割り当てるきまり（関数）を**確率変数**といいます。出血の例なら、次の $Y$ です。

$$
Y(\omega) =
\begin{cases}
1 & \omega \text{ で出血する} \\
0 & \omega \text{ で出血しない}
\end{cases}
$$

同じ結果 $\omega$ に病変径を割り当てれば、別の確率変数 $X$ ができます。一つの確率空間の上に、いくつもの確率変数を考えられます。

確率変数がある値をとる確率は、その値になる結果を集めた事象の確率です。

$$
P(Y = 1) = P(\{\omega : Y(\omega) = 1\}) = p, \quad P(Y = 0) = 1 - p
$$

切除する前には、$Y$ が 0 と 1 のどちらになるかはわかりません。わかっているのは、それぞれの値をとる確率だけです。切除のあとに観察した値は、もう確率変数ではなく、ただの数です。この違いを示すため、確率変数は $Y$ や $X$ のように大文字で、観察した値は $y$ や $x$ のように小文字で書きます。

## 確率分布 {#distribution}

確率変数がどの値をどのくらいの確率でとるかを、**確率分布**といいます。確率変数には二つの種類があります。

- **離散**の確率変数は、出血の有無や出血した人数のように、飛び飛びの値をとります。値ごとの確率 $P(Y = y)$ を並べれば分布が決まり、すべて足すと 1 です。
- **連続**の確率変数は、年齢や病変径のように、続いた値をとります。ちょうど 15.000… mm になる確率は 0 なので、範囲で考えます。$X$ が $a$ と $b$ の間に入る確率は、**確率密度** $f(x)$ の曲線の下の面積です。曲線の下の面積は全体で 1 です。

$$
P(a \le X \le b) = \int_a^b f(x)\, dx
$$

いろいろな分布は [A6](distributions.md)、確率変数の平均（期待値）とばらつき（分散）は [A3](expectation-variance.md) で扱います。

## オッズ

**オッズ**は、起きる確率を起きない確率で割ったものです。

$$
\text{オッズ} = \frac{p}{1 - p}
$$

| $p$ | オッズ |
|-----|--------|
| 0.01 | 0.0101 |
| 0.05 | 0.0526 |
| 0.2 | 0.25 |
| 0.5 | 1 |
| 0.8 | 4 |

- $p$ が 0 に近いと、オッズは $p$ とほぼ同じです。
- $p = 0.5$ でオッズは 1 です。
- $p$ が 1 に近づくと、オッズはいくらでも大きくなります。

オッズから確率に戻すには $p = \text{オッズ} / (1 + \text{オッズ})$ です。

## オッズ比

二つの群のオッズの比が**オッズ比**です。クリップ群のオッズを $O_1$、非クリップ群のオッズを $O_0$ とすると、オッズ比は $O_1 / O_0$ です。1 より小さければ、クリップ群の方がオッズが小さいという意味です。

確率が小さいとき、オッズ比はリスク比（確率の比）とほぼ同じになります。確率が大きいと、両者は離れます。

## 指数

$e$ は約 2.718 の数です。$e^x$ を**指数関数**と呼びます。大事な性質は次の二つです。

$$
e^{a + b} = e^a \times e^b, \qquad e^0 = 1
$$

足し算が、かけ算に変わります。

## 対数

**自然対数** $\log x$ は、指数の逆です。「$e$ を何乗すると $x$ になるか」を表します。

$$
\log e^a = a, \qquad e^{\log x} = x
$$

指数の性質を裏返すと、かけ算が足し算に変わります。

$$
\log (a \times b) = \log a + \log b
$$

$\log x$ は $x > 0$ でしか定義されません。$x = 1$ で 0、$x < 1$ で負、$x > 1$ で正です。

## 対数オッズ（ロジット）

オッズの対数を**対数オッズ**、または**ロジット**と呼びます。

$$
\operatorname{logit}(p) = \log \frac{p}{1 - p}
$$

$p$ は 0 から 1 までですが、対数オッズはどんな実数にもなります。$p = 0.5$ で 0 です。だから、対数オッズなら直線 $\beta_0 + \beta_1 x$ で表しても、確率が 0 未満や 1 を超えることがありません。

## ロジスティック関数

対数オッズを $\eta$（イータ）と書きます。$\eta = \log \{p / (1-p)\}$ を $p$ について解きます。

1. 両辺を指数にする：$e^{\eta} = \dfrac{p}{1 - p}$
2. 分母を払う：$e^{\eta}(1 - p) = p$
3. $p$ を集める：$e^{\eta} = p\,(1 + e^{\eta})$
4. 割る：$p = \dfrac{e^{\eta}}{1 + e^{\eta}} = \dfrac{1}{1 + e^{-\eta}}$

最後の式が**ロジスティック関数**です。$\eta$ が大きいほど $p$ は 1 に、小さいほど 0 に近づきます。

## 係数がオッズ比になる理由

$\eta = \beta_0 + \beta_1 x$ とします。$x$ が 1 増えたときのオッズを比べます。

$$
\frac{\text{オッズ}(x + 1)}{\text{オッズ}(x)}
= \frac{e^{\beta_0 + \beta_1 (x + 1)}}{e^{\beta_0 + \beta_1 x}}
= e^{\beta_1}
$$

$x$ の値によらず、オッズは $e^{\beta_1}$ 倍になります。これがオッズ比です。$x$ が 10 増えれば $e^{10 \beta_1} = (e^{\beta_1})^{10}$ 倍です。
