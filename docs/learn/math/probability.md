# A1. 確率と確率変数

本文で使う確率の考え方を、確率空間、確率変数、確率分布の順にまとめます。

[← 目次](../index.md) · [第 2 章](../independent-risk-factor.md)

## 確率空間 {#probability-space}

確率を扱うには、まず「何が起こりうるか」を決めます。決めるものは三つです。

- **標本空間** $\Omega$（オメガ）：起こりうる結果をすべて集めたもの。サイコロを 1 回振るなら $\Omega = \{1, 2, 3, 4, 5, 6\}$ です。患者を 1 人選んで切除後の経過を見るなら、$\Omega$ はその患者に起こりうる経過すべてです。
- **事象**：標本空間の一部分。「偶数の目が出る」は $\{2, 4, 6\}$ です。「出血する」は、起こりうる経過のうち出血するものを集めた事象です。
- **確率** $P$：事象ごとに、0 から 1 の数を割り当てるきまり。

確率は、次の約束を守ります。

- どの事象 $A$ でも $0 \le P(A) \le 1$
- 何かは必ず起こるので $P(\Omega) = 1$
- 同時には起こらない事象 $A$ と $B$ なら、$P(A \text{ または } B) = P(A) + P(B)$

この約束から、たとえば「$A$ が起こらない確率」は $1 - P(A)$ だとわかります。サイコロなら、どの目も確率 $1/6$ なので、偶数の目が出る確率は $1/6 + 1/6 + 1/6 = 1/2$ です。

標本空間、事象、確率の三つの組を**確率空間**と呼びます。厳密に定めるには測度論という数学が要りますが、本書ではこの理解で十分です。

### 確率の読み方

100 人中 5 人が出血したら、出血割合は $5/100 = 0.05$ です。これを、1 人の患者が出血する確率 $p$ と考えます。同じ状況を何度も繰り返したときに起こる割合として確率を読む見方です。第 14 章のベイズ推論では、確率を「どのくらい確からしいか」の度合いとしても読みます。

## 確率変数 {#random-variable}

標本空間の結果は、「出血した経過」や「6 の目」のように、ことばや記号のこともあります。計算するには数に直します。結果 $\omega$ ごとに数を一つ割り当てるきまり（関数）を**確率変数**といいます。出血の例なら、次の $Y$ です。

$$
Y(\omega) =
\begin{cases}
1 & \omega \text{ で出血する} \\
0 & \omega \text{ で出血しない}
\end{cases}
$$

同じ結果 $\omega$ に病変径を割り当てれば、別の確率変数 $X$ ができます。一つの確率空間の上に、いくつもの確率変数を考えられます。

確率変数がある値をとる確率は、その値になる結果を集めた事象の確率です。

$$
P(Y = 1) = P(\{\omega : Y(\omega) = 1\}) = p, \quad P(Y = 0) = 1 - p
$$

切除する前には、$Y$ が 0 と 1 のどちらになるかはわかりません。わかっているのは、それぞれの値をとる確率だけです。切除のあとに観察した値は、もう確率変数ではなく、ただの数です。この違いを示すため、確率変数は $Y$ や $X$ のように大文字で、観察した値は $y$ や $x$ のように小文字で書きます。

## 確率分布 {#distribution}

確率変数がどの値をどのくらいの確率でとるかを、**確率分布**といいます。確率変数には二つの種類があります。

- **離散**の確率変数は、出血の有無や出血した人数のように、飛び飛びの値をとります。値ごとの確率 $P(Y = y)$ を並べれば分布が決まり、すべて足すと 1 です。
- **連続**の確率変数は、年齢や病変径のように、続いた値をとります。ちょうど 15.000… mm になる確率は 0 なので、範囲で考えます。$X$ が $a$ と $b$ の間に入る確率は、**確率密度** $f(x)$ の曲線の下の面積です。曲線の下の面積は全体で 1 です。

$$
P(a \le X \le b) = \int_a^b f(x)\, dx
$$

いろいろな分布は [A7](distributions.md)、確率変数の平均（期待値）とばらつき（分散）は [A4](expectation-variance.md) で扱います。
