# lmm_pbcseq_discussion

数値は [lmm_pbcseq_results.md](lmm_pbcseq_results.md) の生成物を読む。再集計しない。

## CQ への答え

無作為化 312 人、訪問 1945 行。変量切片 LMM では `day_years` が対数ビリルビンと正の関連（約 +0.095 / 年）。`dp` は約 −0.11（区間は 0 を含む）。患者間分散 1.20 に対し残差 0.24。GAM（主解析、`s(day_years)`、k=8、edf≈2.1）は治療を含まない集団平滑である。クラスタ OLS の `day_years` は点推定が小さく区間が広い（変量切片の有無で平均構造の意味が違う）。

## 当たり外れ

患者間分散が残差より大きく、独立 OLS をそのまま読む根拠は弱い。治療の固定効果は小さい、という読みと LMM の区間は矛盾しない。

## 限界

- GAM API はこの版では平滑1本・ガウスのみで、`dp` と変量切片を入れられない。
- 欠測検査は完全例。MAR の多重代入はしていない。
- `pbcseq` の `trt` は 0/1（横断 `pbc` の 1/2 とは違う）。
- `cif_pbc` と同じ疾患だが解析単位が違う。GPL 教学データ。
